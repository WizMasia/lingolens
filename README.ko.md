# LingoLens 빠른 사용법

LingoLens는 Chrome이 관리하는 기기 내 언어 감지 및 번역 모델로 일반 HTTP·HTTPS 웹페이지의 텍스트를 번역하는 확장 프로그램입니다. 페이지 텍스트를 LingoLens 번역 서버로 보내지 않습니다.

## 필요 환경

- 데스크톱 Chrome 138 이상
- Chrome의 Language Detector 및 Translator API를 사용할 수 있는 기기와 Chrome 설치 환경
- Chrome이 처음 필요한 감지 모델이나 언어 쌍 모델을 받을 때의 네트워크 연결

모델의 제공 여부와 최초 획득은 Chrome이 관리합니다. 필요한 모델을 Chrome이 이미 획득한 뒤에는 네트워크 없이 동작할 수 있지만, 모든 기기와 언어 쌍에서 오프라인 동작을 보장하지는 않습니다.

## 압축 해제 확장 프로그램 설치

```bash
bun install
bun test
bun run check
bun run build
```

1. `chrome://extensions`를 엽니다.
2. **Developer mode**를 켭니다.
3. **Load unpacked**를 선택하고 생성된 `dist` 폴더를 선택합니다.
4. 필요하면 **LingoLens**를 고정합니다.

## 사용 방법

- 팝업에서 **페이지 전체 번역**을 누르면 현재 페이지의 번역을 시작합니다. **원문 복원**을 누르면 LingoLens가 만든 번역을 지웁니다.
- 기본값으로 텍스트를 선택하거나 텍스트 요소 위에 포인터를 둔 상태에서 `Ctrl`을 누르면 해당 요소를 번역합니다. 같은 번역 토글 키를 다시 누르면 원문으로 복원합니다.
- 기본 **언어 메뉴 키**는 `Ctrl + Shift`입니다. 요소 위에서 누르면 요소별 입력·도착 언어 메뉴가 열리고 감지된 입력 언어를 확인하거나 다시 번역할 수 있습니다.
- **설정**의 **번역 설정**에서 **원문 아래 표시** 또는 **호버 시 교체**를 고릅니다. 첫 번째는 원문 다음에 번역문을 추가하고, 두 번째는 가리키거나 포커스한 동안 번역문을 표시합니다.
- **입력 언어**, **도착 언어**, **번역 토글 키**, **언어 메뉴 키**를 정한 뒤 **설정 저장**을 누릅니다.

짧은 텍스트의 자동 감지는 불확실할 수 있습니다. 결과가 맞지 않으면 언어 메뉴에서 입력 언어를 직접 선택하세요.

LingoLens는 브라우저 내부 페이지, Chrome 웹 스토어, PDF 뷰어 내부, 이미지, 동영상 자막, 코드 블록, 편집 가능한 입력 영역, 교차 출처 iframe 콘텐츠는 번역하지 않습니다.

## YouTube Live Chat 상태

YouTube Live Chat은 계획된 YouTube 전용 MVP이며 이 릴리스에는 포함되지 않습니다. 다른 실시간 채팅 서비스 지원을 의미하지 않습니다.

## 모델 및 언어 쌍 제한

Chrome은 기기 내 AI API와 요청한 입력·도착 언어 쌍이 사용 가능, 다운로드 가능, 다운로드 중, 또는 사용할 수 없는지 결정합니다. Chrome 버전만으로 모든 모델과 언어 쌍의 사용 가능성이 보장되지는 않습니다. 모델을 초기화하지 못하면 Chrome 업데이트, 기기 지원 여부, 필요한 모델 획득 상태를 확인하고 가능한 경우 `chrome://on-device-internals`를 확인하세요.
