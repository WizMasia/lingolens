# LingoLens 빠른 사용법

LingoLens는 Chrome이 관리하는 기기 내 언어 감지 및 번역 모델로 일반 HTTP·HTTPS 웹페이지의 텍스트를 번역하는 확장 프로그램입니다. 페이지 텍스트를 LingoLens 번역 서버로 보내지 않습니다.

## 필요 환경

- 데스크톱 Chrome 138 이상
- Chrome의 Language Detector 및 Translator API를 사용할 수 있는 기기와 Chrome 설치 환경
- Chrome이 처음 필요한 감지 모델이나 언어 쌍 모델을 받을 때의 네트워크 연결

모델의 제공 여부와 최초 획득은 Chrome이 관리합니다. 필요한 모델을 Chrome이 이미 획득한 뒤에는 네트워크 없이 동작할 수 있지만, 모든 기기와 언어 쌍에서 오프라인 동작을 보장하지는 않습니다.

## 압축 해제 확장 프로그램 설치

```bash
bun install
bun test
bun run check
bun run build
```

1. `chrome://extensions`를 엽니다.
2. **Developer mode**를 켭니다.
3. **Load unpacked**를 선택하고 생성된 `dist` 폴더를 선택합니다.
4. 필요하면 **LingoLens**를 고정합니다.

## 사용 방법

- 팝업에서 **페이지 전체 번역**을 누르면 현재 페이지의 번역을 시작합니다. **원문 복원**을 누르면 LingoLens가 만든 번역을 지웁니다.
- 기본값으로 텍스트를 선택하거나 텍스트 요소 위에 포인터를 둔 상태에서 `Ctrl`을 누르면 해당 요소를 번역합니다. 같은 번역 토글 키를 다시 누르면 원문으로 복원합니다.
- 기본 **언어 메뉴 키**는 `Ctrl + Shift`입니다. 요소 위에서 누르면 요소별 입력·도착 언어 메뉴가 열리고 감지된 입력 언어를 확인하거나 다시 번역할 수 있습니다.
- **설정**의 **번역 설정**에서 **원문 아래 표시** 또는 **호버 시 교체**를 고릅니다. 첫 번째는 원문 다음에 번역문을 추가하고, 두 번째는 가리키거나 포커스한 동안 번역문을 표시합니다.
- **입력 언어**, **도착 언어**, **번역 토글 키**, **언어 메뉴 키**를 정한 뒤 **설정 저장**을 누릅니다.

짧은 텍스트의 자동 감지는 불확실할 수 있습니다. 결과가 맞지 않으면 언어 메뉴에서 입력 언어를 직접 선택하세요.

LingoLens는 브라우저 내부 페이지, Chrome 웹 스토어, PDF 뷰어 내부, 이미지, 동영상 자막, 코드 블록, 편집 가능한 입력 영역, 일반적인 교차 출처 iframe 콘텐츠는 번역하지 않습니다. 아래의 YouTube Live Chat 전용 경로만 iframe 예외입니다.

## YouTube Live Chat 상태

LingoLens에는 실험적인 YouTube 전용 Live Chat MVP가 포함되어 있습니다. YouTube 시청 페이지나 `/live_chat` 팝아웃에서 **페이지 전체 번역**을 누르면 YouTube Live Chat 프레임의 일반 채팅 메시지 텍스트를 같은 기기 내 모델로 번역할 수 있습니다. Live Chat은 페이지 표시 설정이 인라인이어도 항상 일시적 호버 교체를 사용하므로 채팅 레이아웃에 번역 카드를 추가하지 않습니다.

YouTube `live_chat` 프레임만 처리합니다. 다른 실시간 채팅 서비스, 채팅 입력창, 유료·멤버십 UI, 일반 메시지가 아닌 페이지 콘텐츠는 지원한다고 주장하지 않습니다. 이 실험 경로는 공개 배포 전에 실제 공개 채팅에서 최종 수동 검증이 필요합니다.

### 실험적 라이브 채팅 언어 지원

실험적 Live Chat 언어 지원은 선택 기능이며 기본으로 꺼져 있습니다. 이는 기기 내 분류기이며 번역기가 아닙니다. 즉, 대상이 되는 일반 YouTube Live Chat 메시지의 입력 언어를 추정하도록 돕지만 실제 번역은 계속 Chrome의 번역 모델이 수행합니다. 설정에서 **Gemini Nano 언어 보조 사용**을 켜고 설정을 저장한 뒤 **로컬 모델 준비**를 명시적으로 눌러야 현재 확장 세션에서 사용할 수 있으며, 이 준비 과정에서 Chrome이 관리하는 모델을 Chrome이 다운로드할 수 있습니다.

준비 권한은 의도적으로 현재 세션에만 남습니다. 확장 서비스 워커가 다시 시작되면 Nano 보조를 실행하기 전에 다시 **로컬 모델 준비**를 눌러야 하며, LingoLens가 자동으로 새 모델 다운로드를 시작하지는 않습니다.

Nano 프롬프트는 Chrome 내부에만 머뭅니다. 이 보조 기능은 실험적이며 사용할 수 없거나 부정확할 수 있고, 로마자 표기 힌디어 인식을 보장하지 않습니다. 자동 보조가 불확실하면 설정한 언어 메뉴 키로 작성자에게 힌디어 등 Chrome Translator가 지원하는 입력 언어를 직접 선택하세요. Chrome Translator에 지원되는 우르두어 언어 쌍이 없으므로 로마자 표기 우르두어는 이 방식으로 복구할 수 없습니다.

## 모델 및 언어 쌍 제한

Chrome은 기기 내 AI API와 요청한 입력·도착 언어 쌍이 사용 가능, 다운로드 가능, 다운로드 중, 또는 사용할 수 없는지 결정합니다. Chrome 버전만으로 모든 모델과 언어 쌍의 사용 가능성이 보장되지는 않습니다. 모델을 초기화하지 못하면 Chrome 업데이트, 기기 지원 여부, 필요한 모델 획득 상태를 확인하고 가능한 경우 `chrome://on-device-internals`를 확인하세요.
