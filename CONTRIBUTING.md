# Contributing to LingoLens

Thanks for helping improve LingoLens. Before opening a change, discuss substantial behavior or policy changes in an issue so the scope is clear.

## Development

```bash
bun install
bun test
bun run check
bun run build
```

Keep changes focused, add or update tests for behavior changes, and make documentation match the implementation. Do not add remote translation services, telemetry, permissions, or support claims without an explicit review of their user impact.

## Pull requests

Describe the user-facing change, list the checks you ran, and call out changes to permissions, privacy language, models, or release material. By submitting a contribution, you agree that it may be distributed under the [Apache License 2.0](LICENSE).
