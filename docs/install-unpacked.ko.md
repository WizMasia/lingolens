# LingoLens 사전 릴리즈 설치

이 배포본은 아직 Chrome 웹 스토어용 패키지가 아닙니다. 압축을 푼 폴더를 Chrome 개발자 모드에서 직접 로드합니다.

1. GitHub 릴리즈에서 `LingoLens-<version>-unpacked.zip`을 내려받아 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누른 뒤, 압축을 푼 `LingoLens` 폴더를 선택합니다. `manifest.json`이 그 폴더의 바로 아래에 있어야 합니다.
5. 확장을 고정한 뒤 웹페이지를 새로고침합니다.

Chrome이 언어 감지·번역·Gemini Nano 모델을 처음 준비할 때 네트워크 연결과 기기 여유 공간이 필요할 수 있습니다. Nano 언어 보조는 기본으로 꺼져 있으며, 옵션에서 저장하고 **로컬 모델 준비**를 명시적으로 눌러야 합니다.

이 사전 릴리즈는 YouTube Live Chat과 Nano 보조의 실제 기기별 가용성을 계속 검증 중입니다. 문제가 있으면 저장소의 이슈 템플릿으로 재현 절차와 Chrome 버전을 알려주세요.
