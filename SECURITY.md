# Security policy

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in a public issue. Use private GitHub vulnerability reporting for this repository when it is available, or contact the project's GitHub owner through that profile with enough detail to reproduce the issue.

Include the affected version, Chrome version, steps to reproduce, expected and observed behavior, and any practical impact. Do not include secrets, private page text, or personal data unless it is essential and you have permission to share it.

## Scope

Reports about extension permissions, page-content handling, injected UI, dependencies, and build output are in scope. The maintainers will assess reports privately when possible and coordinate a fix or disclosure response based on severity and reproducibility.
