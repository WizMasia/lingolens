# Code of conduct

LingoLens contributors and maintainers are expected to be respectful, constructive, and considerate of others. Harassment, discrimination, threats, personal attacks, and sharing another person's private information without permission are not acceptable.

If conduct in project spaces concerns you, report it privately through the project's GitHub owner profile. Provide the relevant context and avoid reposting sensitive material publicly. Maintainers may remove content, restrict participation, or take other proportionate action to protect the community.
